# .github

Unlimited Gear（ULG）組織の共通設定リポジトリです。

このリポジトリに置いたファイルは、組織内の **すべてのリポジトリの既定値** として使われます（各リポジトリに同名ファイルがある場合はそちらが優先）。

| パス | 役割 |
| --- | --- |
| `profile/README.md` | 組織のトップページ（github.com/Unlimited-Gear）に表示される紹介文 |
| `ISSUE_TEMPLATE/` | Issue のテンプレート（バグ報告・機能要望・タスク） |
| `PULL_REQUEST_TEMPLATE.md` | Pull Request のテンプレート |
| `CONTRIBUTING.md` | 開発の進め方（ブランチ、コミット、レビュー） |
| `SECURITY.md` | トークン流出などセキュリティ問題の報告方法 |
| `docs/ORG_GUIDE.md` | 組織の運用ルール（権限、命名、ラベル、シークレット） |
| `docs/ORG_SETTINGS.md` | 組織の設定チェックリスト（Owner 向け） |

> このリポジトリは **Public** にしてください。Public でないと既定のテンプレートが他リポジトリに適用されず、プロフィールも表示されません。機密情報は置かないでください。
